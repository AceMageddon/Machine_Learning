# Machine Learning: PyTorch lab work

Eight Jupyter notebooks from a deep-learning course at the Financial University, solved in Python with PyTorch. The assignment texts are in Russian and were written by the course instructor; the code solutions are mine. Uploaded in 2023.

| Notebook | Topic |
|---|---|
| `ПИ19-4_Глазунов_Лаб1` | PyTorch tensors: creation, broadcasting, indexing and masking, maths without Python loops |
| `ПИ19-4_Глазунов_Лаб2` | A neural network from scratch: neurons, fully connected layers, activation functions, a loss function and backpropagation built from tensor operations |
| `ПИ19-4_Глазунов_Лаб3` | Autograd, optimisers in `torch.optim`, models with `torch.nn`, `Dataset` and `DataLoader` |
| `ПИ19-4_Глазунов_Лаб4.3` | Transfer learning: image classification with a pretrained VGG16 from torchvision |
| `ПИ19-4_Глазунов_Лаб5` | Text classification with feed-forward networks: preprocessing with NLTK, surnames by nationality, restaurant reviews |
| `ПИ19-4_Глазунов_Лаб6` | Text classification with convolutional networks: word sequences and embeddings, surnames by nationality, film reviews |
| `ПИ19-4_Глазунов_Лаб7` | A second, reworked solution of the convolutional-network assignment |
| `ПИ19-4_Глазунов_Лаб8` | Recurrent networks: generating Russian first names and text with an RNN |

Libraries: PyTorch, torchvision, scikit-learn, pandas, NLTK, Matplotlib, seaborn.

Учебные лабораторные работы по машинному обучению, Финансовый университет.
